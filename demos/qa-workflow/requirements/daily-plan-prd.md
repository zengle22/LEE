# 每日训练计划功能 PRD

## 功能概述

每日训练计划模块为用户提供个性化的7日训练计划，根据用户的跑步历史、目标赛事和当前状态动态调整。

## 核心功能

### 1. 计划生成

- 根据用户目标赛事自动生成7日计划
- 包含每日训练类型（轻松跑、间歇跑、长距离等）
- 显示每日目标配速、距离和预估时长

### 2. 配速计算

- 根据用户历史配速计算训练配速区间
- 支持心率区间映射
- 考虑疲劳度进行动态调整

### 3. 降级处理

- 新用户无历史数据时显示默认计划
- 网络异常时显示缓存计划
- 数据异常时显示安全兜底

## 验收标准

1. 用户登录后可在首页看到7日训练计划
2. 每日计划包含：训练类型、目标配速、目标距离、预估心率
3. 配速区间计算准确，误差不超过5%
4. 新用户首次使用可正常显示降级计划
5. 页面加载时间不超过2秒

## 边界条件

- 最小周跑量：10km
- 最大周跑量：200km
- 连续休息天数上限：3天
- 配速范围：3:00/km - 10:00/km

## 技术依赖

- 后端 API：`/api/v1/plan/weekly`
- 数据库：用户跑步历史表、计划缓存表
- 外部服务：天气服务（用于计划微调）
