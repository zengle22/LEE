# FEAT-SRC-059-003: Hard Gate 与 Quality Signal 分层

## 目标

在 fitness_executor 中实现规则分层机制，为 Supervisor 和 Gate 审批者提供明确的阻断信号。

## 用户价值

为 Supervisor 和 Gate 审批者提供明确的阻断信号，hard_gate 失败时 agent 无法宣布退出循环。

## 输入契约

**必需工件**:
- FEAT-SRC-059-002 draft fitness_executor module
- EPIC-SRC-059-001 frozen spec
- gate_template.governance.fitness_gate baseline

**必需字段**:
- rule_type
- overall_pass
- hard_gate_failed
- dimension_scores

**消费规则**:
- hard_gate 失败时必须设置 overall_pass=false 且 hard_gate_failed=true
- quality_signal 失败时仅记录 dimension 扣分不影响 overall_pass
- 提供 gate_template.governance.fitness_gate 模板供下游复用

## 处理逻辑

1. 在 fitness_executor 中实现规则分层判断逻辑
2. hard_gate 失败时设置 overall_pass=false 和 hard_gate_failed=true
3. quality_signal 失败时仅累加 dimension 扣分
4. 提供 gate_template.governance.fitness_gate 模板

## 输出

- `skill/governance/fitness_executor/layering.py` - 分层逻辑实现
- `gate_template/governance/fitness_gate.py` - fitness gate 模板
- `test_fitness_layering.py` - 分层逻辑单元测试

## 验收标准

4. 提供 gate_template.governance.fitness_gate 模板供复用
