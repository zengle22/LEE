# FEAT-SRC-059-004: Fitness Result 结构化输出

## 目标

定义 fitness_result.json 的 schema 和输出格式，为 Supervisor、Gate 审批者和工程治理团队提供可消费的完成证明。

## 用户价值

为 Supervisor、Gate 审批者和工程治理团队提供可消费的完成证明，无需手工拼接完成条件。

## 输入契约

**必需工件**:
- FEAT-SRC-059-002 draft fitness_executor output schema
- FEAT-SRC-059-003 draft layering output schema
- EPIC-SRC-059-001 frozen spec

**必需字段**:
- overall_pass
- hard_gate_results
- dimension_results
- evidence_links
- executed_at
- rules_version

**消费规则**:
- overall_pass 必须为布尔值表示整体通过状态
- hard_gate_results 必须为数组包含每个 hard_gate 的执行详情
- dimension_results 必须包含规则覆盖率和执行追踪视图
- evidence_links 必须支持回挂到 evidence pack 的链接结构
- 输出格式必须可被现有 gate 语义消费

## 处理逻辑

1. 定义 fitness_result.json 的 schema 结构
2. 实现 overall_pass、hard_gate_results、dimension_results、evidence_links 字段
3. 设计可被现有 gate 语义消费的输出格式
4. 实现 evidence pack 回挂链接结构

## 输出

- `fitness_result.schema.json` - 输出结果 schema 定义
- `skill/governance/fitness_result_formatter.py` - 结果格式化器
- `test_fitness_result_schema.py` - schema 验证测试

## 验收标准

1. 定义 fitness_result.json 的 schema 包含 overall_pass、hard_gate_results、dimension_results、evidence_links
2. overall_pass 为布尔值表示整体通过状态
3. dimension_results 包含规则覆盖率和执行追踪视图
4. 输出格式可被现有 gate 语义消费
5. 支持回挂到 evidence pack 的链接结构
