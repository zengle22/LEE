# FEAT-SRC-059-005: CLI 与 CI 集成

## 目标

实现 lee fitness run 和 validate 命令，为 AI 执行器和 CI 流水线提供统一的完成条件执行入口。

## 用户价值

为 AI 执行器和 CI 流水线提供统一的完成条件执行入口，使 fitness 检查可被自动化触发。

## 输入契约

**必需工件**:
- FEAT-SRC-059-001 output fitness_rule.schema.json and validate tool
- FEAT-SRC-059-002 output fitness_executor module
- FEAT-SRC-059-004 output fitness_result formatter
- GitHub Actions CI/CD specification

**必需字段**:
- rules_dir
- output_file
- exit_code
- ci_template

**消费规则**:
- lee fitness run 必须支持 --rules-dir 和 --output-file 参数
- lee fitness validate 必须用于 schema 验证
- 执行失败时必须返回非零 exit code
- 必须提供 CI 模板片段可在 GitHub Actions 中调用

## 处理逻辑

1. 实现 lee fitness run 命令支持 --rules-dir、--output-file 参数
2. 实现 lee fitness validate 命令用于 schema 验证
3. 集成 fitness_executor 执行规则并输出 fitness_result
4. 提供 GitHub Actions CI 模板片段

## 输出

- `lee/cli/commands/fitness.py` - CLI 命令实现
- `ci-templates/fitness-github-action.yml` - GitHub Actions 模板
- `test_fitness_cli.py` - CLI 集成测试

## 验收标准

1. 实现 lee fitness run 命令支持 --rules-dir、--output-file 参数
2. 实现 lee fitness validate 命令用于 schema 验证

4. 执行失败时返回非零 exit code

## 验收检查

| ID | 场景 | Given | When | Then |
|----|------|-------|------|------|
| AC-001 | 执行 lee fitness run 命令 | 存在包含 fitness_rule.yaml 的规则目录 | 执行 lee fitness run --rules-dir \<dir\> --output-file \<file\> | 生成 fitness_result.json 并返回零退出码 |
