# FEAT-SRC-059-002: Fitness Executor 核心实现

## 目标

实现 skill.governance.fitness_executor 模块，为 AI 执行器提供统一的完成条件扫描与聚合入口。

## 用户价值

为 AI 执行器提供统一的完成条件扫描与聚合入口，使 agent 能获取全局完成信号而非仅依赖局部判断。

## 输入契约

**必需工件**:
- FEAT-SRC-059-001 draft fitness_rule.schema.json
- EPIC-SRC-059-001 frozen spec
- Python 3.10+ subprocess module documentation

**必需字段**:
- rules_dir
- rule_files
- command_results
- aggregated_output

**消费规则**:
- scan_rules() 必须返回指定目录下所有 fitness_rule.yaml 文件路径列表
- execute_commands() 必须执行规则中定义的 command 并捕获 stdout/stderr/exit_code
- aggregate_results() 必须返回结构化执行结果包含 per-rule 和 summary 视图

## 处理逻辑

1. 实现 skill.governance.fitness_executor 模块
2. 实现 scan_rules() 接口扫描指定目录下的 fitness_rule.yaml 文件
3. 实现 execute_commands() 接口执行规则命令并捕获输出
4. 实现 aggregate_results() 接口聚合执行结果
5. 返回结构化执行结果包含 rule_id、exit_code、stdout、stderr、duration

## 输出

- `skill/governance/fitness_executor/__init__.py` - 执行器模块入口
- `skill/governance/fitness_executor/scanner.py` - 规则扫描器实现
- `skill/governance/fitness_executor/executor.py` - 命令执行器实现
- `skill/governance/fitness_executor/aggregator.py` - 结果聚合器实现
- `test_fitness_executor.py` - 单元测试套件

## 验收标准

3. 执行规则中定义的 command 并捕获 stdout/stderr/exit_code
