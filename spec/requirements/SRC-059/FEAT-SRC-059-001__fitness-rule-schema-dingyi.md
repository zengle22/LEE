# FEAT-SRC-059-001: Fitness Rule Schema 定义

## 目标

定义 fitness_rule.yaml 的 JSON schema 及验证工具，为治理团队和 AI 执行器提供统一的 fitness 规则描述语言。

## 用户价值

为治理团队和 AI 执行器提供统一的 fitness 规则描述语言，使完成条件可被机器扫描和验证。

## 输入契约

**必需工件**:
- EPIC-SRC-059-001 frozen spec
- JSON Schema Draft 2020-12 specification
- YAML 1.2 specification

**必需字段**:
- rule_id
- rule_type
- scan_command
- pass_criteria
- description

**消费规则**:
- schema 必须支持 YAML 和 JSON 两种输入格式
- rule_type 必须为 hard_gate 或 quality_signal 枚举值
- 验证失败时必须输出结构化错误信息包含行号和字段路径

## 处理逻辑

1. 设计 fitness_rule.yaml 的 JSON schema 结构
2. 定义 rule_id、rule_type、scan_command、pass_criteria 字段的类型与约束
3. 实现 schema 验证工具支持 YAML/JSON 双格式
4. 实现结构化错误输出包含行号与字段路径

## 输出

- `fitness_rule.schema.json` - JSON schema 定义文件
- `validate_fitness_rule.py` - schema 验证工具脚本
- `fitness_rule_example.yaml` - 示例规则文件
- `fitness_rule_example.json` - JSON 格式示例规则文件

## 验收标准

1. 定义 fitness_rule.yaml 的 JSON schema 包含 rule_id、rule_type、scan_command、pass_criteria 字段
2. 提供 schema 验证工具支持 YAML 和 JSON 两种格式
3. 验证通过时不输出错误且返回零退出码
4. 验证失败时输出结构化错误信息包含行号和字段路径

## 验收检查

| ID | 场景 | Given | When | Then |
|----|------|-------|------|------|
| AC-001 | schema 验证工具验证合法的 fitness rule 文件 | 存在符合 schema 的 fitness_rule.yaml 文件 | 执行 validate_fitness_rule.py 验证该文件 | 验证通过且不输出错误，返回零退出码 |
| AC-002 | schema 验证工具检测非法 fitness rule 文件 | 存在不符合 schema 的 fitness_rule.yaml 文件 | 执行 validate_fitness_rule.py 验证该文件 | 验证失败并输出结构化错误信息包含行号和字段路径 |
| AC-003 | schema 支持 YAML 和 JSON 双格式 | 存在分别符合 schema 的 YAML 和 JSON 格式规则文件 | 对两种格式文件分别执行验证 | 两种格式均能通过验证 |
