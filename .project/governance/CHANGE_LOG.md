# Governance Change Log

Use this log only for governance-level changes.

Do not use it as a generic development diary. Normal code evolution belongs in git history.

## What should be recorded

- Acceptance Brief creation, retirement, or upgrade
- Module Contract boundary changes
- acceptance standard changes
- pass threshold changes
- truth-source migration decisions
- gate requirement changes

## Entry Template

### [YYYY-MM-DD] [task-id / module]

#### Changed

- item 1
- item 2

#### Why

- reason 1
- reason 2

#### Truth Source

- acceptance brief / module contract / formal ssot object / approved note

#### Evidence

- artifact path
- test result
- review note

#### Risk

- risk 1
- risk 2

#### Human Gate

- required / not required
- approved by / pending
