# Module Contracts

Module Contracts are minimum boundary cards for critical LEE infrastructure modules during the transition period.

They are not replacements for:

- formal contract schemas in `spec-global/`
- runtime code
- formal SSOT object definitions

They exist to make ownership, invariants, and forbidden semantic drift explicit while the system is still being tightened.

Current first-wave contracts:

- artifact-registry
- path-manager
- workflow-runtime
- gate-flow
- agent-spec-maintainer
