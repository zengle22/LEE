### 🔴 CRIT-003: 数据库事务安全问题

**严重程度**: Critical | **优先级**: P0 | **类别**: Error Handling

**文件**: `src/lee/orchestrator/storage/sqlite_store.py` (行 116-123)

**问题描述**:
事务回滚失败时只打印警告，不重新抛出异常：

```python
except Exception as rollback_error:
    # 回滚失败，记录错误但不掩盖原始异常
    print(f"Warning: ROLLBACK failed: {rollback_error}")
raise e
```

**影响分析**:
- ❌ 数据库状态可能不一致
- ❌ 静默的数据损坏风险

**修复建议**:
1. 使用日志系统替代 `print`
2. 考虑更严格的错误处理策略
3. 添加监控告警

**预计工作量**: 3 小时
