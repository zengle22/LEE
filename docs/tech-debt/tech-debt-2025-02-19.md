### DEBT-001: 硬编码的 API 密钥泄露

**类别**: 安全
**严重程度**: 严重

**问题描述**:
多个 API 密钥被硬编码在配置文件中并提交到版本控制，造成严重的安全漏洞。

**位置**:
- `config/llm_config.yaml:37` - 智谱 API 密钥
- `config/llm_config.yaml:76` - 华为 DeepSeek API 密钥
- `config/llm_config.yaml:90` - MiniMax API 密钥
- `config/llm_config.yaml:103` - DeepSeek API 密钥

**风险**: 密钥泄露可能导致财务损失和滥用

**建议措施**:
1. ✅ **立即**撤销所有暴露的 API 密钥
2. 将所有密钥移动到环境变量或密钥管理系统
3. 从 git 历史中清除敏感信息（使用 git-filter-repo 或 BFG Repo-Cleaner）
4. 添加 pre-commit hook 检测敏感信息
5. 将 `config/llm_config.yaml` 添加到 `.gitignore`

**预计工作量**: 2 小时

**严重程度**: 严重

### DEBT-003: 路径穿越防护不完整

**类别**: 安全
**严重程度**: 严重

**问题描述**:
`safe_join()` 函数可能被绕过，导致目录遍历攻击。仅检查路径前缀，未考虑符号链接攻击和 Windows 路径特殊情况。

**位置**:
- `src/lee/runtime/executor/tools/security.py:13-40`

**代码示例**:
```python
def safe_join(root: str, rel_path: str) -> Optional[str]:
    try:
        root_path = pathlib.Path(root).resolve()
        joined_path = (root_path / rel_path).resolve()

        # ⚠️ 仅检查路径前缀，可能被绕过
        if str(joined_path).startswith(str(root_path)):
            return str(joined_path)
        else:
            return None
```

**风险**: 可能导致访问任意文件系统路径

**建议措施**:
1. 使用 `pathlib.Path.resolve()` 规范化所有路径
2. 检查符号链接是否指向工作区外
3. 添加更多边界条件测试
4. 考虑使用 chroot 或容器隔离

**预计工作量**: 6 小时

**类别**: 代码质量
**严重程度**: 严重

**问题描述**:
SQLite 操作未使用事务，可能在多线程环境下出现数据竞争和不一致。

conn = sqlite3.connect(str(db_path))

    cursor = conn.cursor()
    cursor.execute(...)
    # ⚠️ 无事务管理

3. 添加重试机制处理并发冲突
4. 考虑迁移到支持更好并发的数据库

**代码示例**:
```python
def _load_yaml(self, path: Path) -> Dict[str, Any]:
    if not path.exists():
        logger.debug(f"Config file not found: {path}, using defaults")
        return {}

    try:
        import yaml
        with open(path, "r", encoding="utf-8") as f:
            data = yaml.safe_load(f) or {}
        logger.info(f"Loaded config from {path}")
        return data
    except ImportError:
        logger.warning("PyYAML not installed, using defaults")
        return {}
    except Exception as e:
        logger.warning(f"Failed to parse config file {path}: {e}, using defaults")
        return {}  # ⚠️ 静默降级，丢失错误详情
```

**风险**: 难以诊断配置问题

**建议措施**:
