# v0.1.0 - 2026-01-22

## 🎉 初始版本

这是 LEE 框架的第一个正式版本，提供了完整的 AI 工作流编排能力。

## 新增 (Added)

### 核心代码包 - flowcore

- **orchestrator/**：工作流编排器
  - DAG 调度和执行
  - 状态管理和事件溯源
  - 人工门禁处理
  - Token 管理
- **engines/**：执行引擎系统
  - Legacy Executor 适配层
  - 单 Agent 引擎（计划中）
  - Python/CLI 执行引擎（计划中）
- **utils/**：工具模块
  - 日志工具
  - 事件总线
  - 模板解析器
- **cli/**：命令行工具

### Spec 全局规范

- **core/**：平台级基础规范
  - 通用 workflow 模板
  - 基础对象定义（bug、feature、incident）
  - 通用门禁策略
- **departments/**：按部门组织的规范
  - pm/：产品管理规范
  - dev/：开发规范
  - qa/：测试规范
  - ops/：运维规范
- **cross/**：跨部门协作
  - E2E 工作流模板
  - 部门间接口契约

### 文档体系

- 框架级文档（docs/）
- 模块级文档（flowcore/*/README.md）
- 架构和设计文档
- 变更日志体系（changelogs/）

### 配置和工具

- Workspace 配置模板
- 自动化迁移脚本
- Import 路径更新工具

## 变更 (Changed)

### 从现有项目重组

本版本从以下项目重组而来：

- **orchestrator/**：原有编排器模块
  - 路径：`orchestrator/core/*` → `flowcore/orchestrator/*`
  - 扁平化目录结构
- **Legacy Executor 适配层**：Legacy Executor 集成
  - 路径：`Legacy Executor/legacy_executor/lee/*` → `flowcore/engines/legacy_executor/*`
  - **仅保留适配层代码**：不包含 Legacy Executor 源码，通过 pip 安装
  - **版本固定策略**：`legacy_executor>=0.8.0,<0.9.0` 确保兼容性
  - **依赖管理**：详见 [docs/Dependency-Management.md](../docs/Dependency-Management.md)
- **ai-spec/**：规范定义
  - 路径：`ai-spec/specs/common/*` → `spec-global/departments/*`
  - 按部门重组

## 设计决策

### 核心代码包命名：flowcore

选择 **flowcore** 作为核心代码包名称的原因：

- **简洁**：一个单词，容易输入和记忆
- **语义清晰**：flow（流程）+ core（核心）= 流程编排核心
- **专业**：符合技术命名惯例
- **可扩展**：未来可以有 flowcore-* 的相关包

### Spec 按部门组织

采用 **core/departments/cross** 三层结构：

- **core/**：平台级基础规范（不归任何部门）
- **departments/**：按部门垂直切分（pm/dev/qa/ops）
- **cross/**：跨部门流程和接口

这种结构既体现了"AI 一人公司"的组织思想，又为跨部门协作提供了专门的区域。

## 兼容性 (Compatibility)

### Import 路径变化

**原始路径**：
```python
from orchestrator.core.state_machine import StateMachine
from legacy_executor.lee.protocol import LEERequest
```

**新路径**：
```python
from flowcore.orchestrator.state_machine import StateMachine
from flowcore.engines.legacy_executor.protocol import LEERequest
```
