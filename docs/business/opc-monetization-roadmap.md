# OPC 变现路线图

## 1. 目标

本路线图面向个人 OPC 场景，目标不是先做大平台，而是先建立现金流、案例和可复制交付。

核心原则：

- 先卖结果，不先卖平台
- 先卖服务，不先赌 SaaS
- 先跑通单点试点，再标准化产品
- 用开源建立信任，用服务拿现金流，用模板包提升毛利

## 2. 推荐路径

```text
内容/开源建立信任
  -> 诊断单
  -> 试点代建单
  -> 月度陪跑/顾问订阅
  -> 模板包/私有增强
  -> 产品化
```

## 3. 阶段拆解

### 阶段 1：诊断单

目标：

- 拿到第一笔收入
- 验证客户是否真的有治理痛点
- 形成标准诊断模板

建议产品：

- AI 研发治理诊断

建议交付：

- 当前问题清单
- 风险评级
- 三轴对象和流程断点图
- 30/60/90 天改造建议

建议价格区间：

- RMB 2999 - 9999：试水版
- RMB 10000 - 30000：正式版

### 阶段 2：试点代建单

目标：

- 用一个真实 FEAT 或一个真实 release 跑通最小治理闭环
- 把抽象方法变成客户可感知结果

建议产品：

- AI 研发治理试点代建

建议范围：

- 只做一个 FEAT 的正式输入到 QA 验收
- 或只做一个 release 的 TESTPLAN / TASK / REPORT / EVI 收口
- 或只做 Dev workflow / QA harness 的局部治理改造

建议价格区间：

- RMB 10000 - 50000：小试点
- RMB 50000 - 100000：中型试点

### 阶段 3：月度陪跑

目标：

- 建立稳定现金流
- 持续沉淀案例、模板和规则

建议产品：

- AI 治理陪跑顾问

建议内容：

- 每周同步
- release 节点评审
- workflow / template 调优
- 复盘和经验沉淀

建议价格区间：

- RMB 5000 - 15000 / 月：轻量版
- RMB 20000+ / 月：深度版

### 阶段 4：标准包

目标：

- 把高频交付沉淀成复用资产
- 提高单位时间产出

建议标准包：

- 三轴 SSOT 初始化包
- QA harness 快速接入包
- Release governance 模板包
- Dev workflow 最小治理包
- 复盘与知识沉淀模板包

### 阶段 5：产品化

目标：

- 把已验证的高频能力变成稳定产品能力

优先产品化对象：

- release check
- evidence pack
- QA execution governance
- workflow provenance / audit
- 可视化交付看板

## 4. 客户优先级

最适合起步的客户：

- 10 - 100 人技术团队
- 已经大量使用 Claude / Cursor / Copilot / Codex
- 团队流程开始混乱，但没有内部平台团队
- 有交付、验收、审计或客户压力

不建议优先：

- 超大型企业正式招投标项目
- 需要复杂采购和合规认证的客户
- 只想买纯培训、不愿做真实改造的客户

## 5. 获客方式

推荐获客组合：

- 开源样例
- 高质量内容
- 熟人转介绍
- 定向私信/邮件外联

内容题材建议：

- 为什么团队用了 AI 反而更乱
- 为什么 AI coding 不等于 AI 研发治理
- 为什么 release 级治理是刚需
- 如何用最小治理闭环控制 AI 研发风险

## 6. 开源与收费边界

开源部分：

- 核心理念
- 基础对象模型
- 基础 workflow / schema / demo
- 黄金路径样例

收费部分：

- 诊断和试点交付
- 私有模板包
- 多项目治理增强
- 深度集成
- 陪跑顾问和支持服务

## 7. 60 天执行建议

### 第 1 - 10 天

- 明确一句话定位
- 明确 2 - 3 个服务产品名
- 做落地页或 README 首页
- 准备最小 demo

### 第 10 - 20 天

- 写 2 篇内容
- 准备诊断问卷
- 固化诊断报告模板

### 第 20 - 40 天

- 找 30 个潜在客户做定向触达
- 拿 5 个沟通机会
- 成交 1 个诊断单

### 第 40 - 60 天

- 从诊断单转 1 个试点单
- 边交付边沉淀模板
- 开源通用部分

## 8. 当前建议

如果只能做一件事，优先把“诊断单”打磨出来。  
如果只能交付一个服务，优先交付“AI 研发治理诊断”。

原因：

- 最容易卖
- 最容易形成标准模板
- 最容易导向试点单
- 最适合个人 OPC 起步
