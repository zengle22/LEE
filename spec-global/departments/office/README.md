### workspace-cleanup (工作区整理)

**版本**: v1
**路径**: `workflows/workspace-cleanup/v1/workflow.yaml`

完整的工作区整理流水线：

1. **文件价值判断** - 识别临时文件、编译中间产物，更新 .gitignore
2. **文档整理** - 分门别类整理文档，补充元数据（作者、日期、版本号）
3. **代码文档审查** - 全面审查代码和文档，生成技术债文档（仅记录，不修复）
4. **原子化提交** - 分批创建原子化的 Git 提交
5. **推送远程** - 安全推送到远程仓库

**关键特性**:
- 自动识别并 gitignore 临时文件和构建产物
- 智能文档分类和元数据补充
- 生成结构化技术债文档
- 遵循 Conventional Commits 规范
- 多个人工审核门禁确保安全
