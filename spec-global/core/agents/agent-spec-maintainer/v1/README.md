# Agent Spec Maintainer

## 概述

Agent Spec Maintainer 是一个用于创建和维护 Agent 规范的专用 Agent。它确保所有 Agent 定义遵循统一标准，并提供完整的创建、更新和版本管理能力。

## 使用场景

### 1. 创建新 Agent

当需要定义一个新的 Agent 时，可以描述其职责和能力要求：

```
帮我创建一个名为 code-reviewer 的 Agent，用于：
- 审查代码质量
- 检查代码规范
- 提供改进建议
```

### 2. 更新现有 Agent

对现有 Agent 进行小幅修改：

```
更新 google-keyword-searcher Agent：
- 添加 browser_scroll 工具权限
- 更新 temperature 为 0.3
```

### 3. 版本升级

当需要进行破坏性变更时，升级到新版本：

```
将 product-goal-analyzer Agent 升级到 v2 版本：
- 修改输出契约为新版本
- 添加新的工作流步骤
```

## 详细工作流程

```
用户需求
    ↓
┌─────────────┐
│  理解需求   │ ← 分析用户描述，确定 Agent 类型和核心职责
└─────────────┘
    ↓
┌─────────────┐
│ 检查现有规范 │ ← 避免创建重复或冲突的 Agent
└─────────────┘
    ↓
┌─────────────┐
│ 设计规范内容 │ ← 确定 ID、职责、权限、工作流等
└─────────────┘
    ↓
┌─────────────┐
│ 生成规范文件 │ ← 创建 agent.yaml 和 README.md
└─────────────┘
    ↓
┌─────────────┐
│  验证规范   │ ← 检查格式、字段、命名规范
└─────────────┘
    ↓
   完成
```

## 生成文件说明

### agent.yaml

必须生成的规范文件，遵循模板格式，包含：
- 基础标识 (id, version, type)
- 职责定义 (responsibility)
- 输入输出规范 (inputs, outputs)
- 权限声明 (permissions)
- 工作流程 (workflow) - 可选但建议
- 禁止行为 (forbidden_behaviors) - 可选但建议

### README.md

可选的扩展说明文档，当以下情况时建议创建：
- Agent 工作流程复杂，需要详细说明
- 有特殊配置或使用注意事项
- 需要提供详细的输入输出示例
- 有版本变更历史需要记录

## 命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| 目录名 | kebab-case | `agent-spec-maintainer` |
| Agent ID | snake_case | `agent_spec_maintainer` |
| 版本 | v + 数字 | `v1`, `v2` |

## 注意事项

1. **不要修改模板文件** - `_template` 目录下的文件是参考模板，不应被修改
2. **避免重复职责** - 创建前检查是否已有类似职责的 Agent
3. **遵循命名规范** - 目录名和 ID 必须遵循约定格式
4. **版本管理** - 重大变更时创建新版本，保留旧版本
5. **验证必填字段** - 确保所有必填字段都已正确填写
