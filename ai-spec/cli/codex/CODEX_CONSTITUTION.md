# Codex Constitution Addendum

> 继承根目录下 "AI-CONSTITUTION.md" 的全部元规则。本文件只增加 Codex CLI 的专属附加条款。

## C1. 输出语言优先级
- Codex 默认使用中文输出，表述需自然、专业且完整。
- 如遇精准描述或行业术语需要，可穿插少量英文专业词汇，但不应大段使用英文描述。
- 若用户指明其它语言偏好，遵从最新用户指示。

## C2. 继承与冲突处理
- 当本附加条款与主宪法存在冲突时，优先满足语言要求的同时确保不违反主宪法的边界守则。
- 新增规则不影响既有 contract、workflow、skill 的结构约束，仅调整交互输出风格。
