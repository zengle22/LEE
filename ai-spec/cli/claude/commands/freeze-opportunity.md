## 操作路由

### 1. 如果 action 为空或 "help"

展示帮助信息：

```
🎯 商业机会冻结工具

使用方法：
  /freeze-opportunity freeze              - 执行商业机会冻结流程
  /freeze-opportunity freeze --from RF-xxx - 从指定需求调研冻结开始
  /freeze-opportunity freeze --force      - 强制重新执行
  /freeze-opportunity status              - 查看当前冻结状态
  /freeze-opportunity list                - 查看所有冻结报告
  /freeze-opportunity help                - 显示帮助

核心流程：
  1. 读取需求调研冻结 (RF-xxx)
  2. 执行商业机会分析 (business-opportunity-analyzer)
  3. 人类确认商业机会
  4. 冻结交付产品部门

前置条件：
  需要先完成需求调研冻结 (/freeze-research)

输出：
  opportunity-freeze.md (OF-YYYYMMDD-XXX)

下一步：
  冻结完成后运行 /prd 进行产品设计
```

### 2. 如果 action 为 "status"

显示冻结状态：

#### Step 1: 扫描相关报告

```
1. Glob 搜索: output/*research-freeze*.md 或 *RF-*.md
2. Glob 搜索: output/*商业机会*.md 或 *-opportunity-BO-*.md
3. Glob 搜索: output/*opportunity-freeze*.md 或 *OF-*.md
```

#### Step 2: 解析关联关系

追踪关联：
- 需求调研冻结 → 是否有对应的商业机会分析
- 商业机会分析 → 是否已冻结

#### Step 3: 生成状态报告

```

┌─────────────────────────────────────────────────────────────────────────┐
│ 机会链状态                                                               │
├─────────────────────────────────────────────────────────────────────────┤
│ # │ 需求调研冻结 │ 商业机会分析 │ 机会冻结 │ 状态                       │
│───│─────────────│─────────────│─────────│──────────────────────────│
│ 1 │ RF-001      │ BO-001      │ OF-001  │ 🔒 已冻结，可进入产品设计  │
│ 2 │ RF-002      │ BO-002      │ -       │ ⏳ 待冻结                  │
│ 3 │ RF-003      │ -           │ -       │ ⚠️ 待分析                  │
└─────────────────────────────────────────────────────────────────────────┘

统计：
  • 需求调研冻结数: 3
  • 已完成商业机会冻结: 1

  • 待分析: 1 (缺少商业机会分析)

💡 运行 /freeze-opportunity freeze 处理待冻结的报告
💡 缺失商业机会分析的需先运行 /analyze-opportunity
```

### 3. 如果 action 为 "freeze"

执行完整商业机会冻结流程：

#### Step 0: 检查前置条件

**0.1 检查需求调研冻结**

```
Glob 搜索: output/*research-freeze*.md
         或 output/RF-*.md
```

如果未找到需求调研冻结：

```
❌ 无法执行商业机会冻结

原因: 未找到需求调研冻结文档

前置条件:
  ✅ 热词调研 (TR-xxx) - 需先完成
  ✅ 三维并行分析 - 需先完成
  ❌ 需求调研冻结 (RF-xxx) - 缺失

请先运行:
  /freeze-research freeze

完成需求调研冻结后，再运行 /freeze-opportunity freeze
```

**0.2 如果指定了 --from**
- 验证指定的 RF 报告存在
- 检查是否已有对应的 OF 冻结

**0.3 如果未指定 --from**
- 扫描所有 RF 报告
- 找出尚未冻结的
- 选择最新的进行处理

```
🔍 分析商业机会冻结任务

找到需求调研冻结: RF-20260105-001

  • 机会冻结: {存在 OF-xxx / 缺失}

{下一步提示}
```

## 错误处理

### 需求调研冻结缺失

```
❌ 无法执行商业机会冻结

原因: 未找到需求调研冻结文档

流程要求:
  热词调研 → 三维分析 → 需求调研冻结 → 商业机会冻结
                           ↑
                        当前缺失

请先运行:
  /freeze-research freeze

完成需求调研冻结后，再运行 /freeze-opportunity freeze
```

### 商业机会分析失败

```
⚠️ 商业机会分析失败

可能原因:
1. 需求调研冻结数据不完整
2. 市场数据获取失败

建议:
1. 检查需求调研冻结内容
2. 手动运行 /analyze-opportunity 单独生成
3. 重新运行 /freeze-opportunity freeze
```

### 人类拒绝商业机会

```
⚠️ 商业机会被拒绝

拒绝原因: "{user_reason}"

此商业机会将被标记为"已拒绝"，不会生成冻结报告。

选项:
1. 运行 /analyze-opportunity 重新分析
2. 调整搜索关键词，从头开始调研
3. 放弃此方向，探索其他机会
```

5. **追溯清晰**: 可追溯到需求调研冻结和原始分析
