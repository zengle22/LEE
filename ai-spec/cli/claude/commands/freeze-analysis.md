# 分析冻结

你正在使用分析冻结工具。本工具评审竞品供给分析、行业结构分析、用户信号分析三份报告的质量，不合格则要求返工，全部合格后整合并冻结为最终分析。

## 契约说明

- **输入契约**:
  - `contracts/trend-research-contract.md` (热词调研输出)
  - `contracts/business-opportunity-contract.md` (商业机会分析输出)
- **输出契约**: `contracts/frozen-analysis-contract.md` (冻结分析输出)

## 追踪机制

通过 **Contract ID 关联** 追踪处理状态：

```
热词调研报告: TR-YYYYMMDD-XXX
    ↓ 商业分析后
商业机会报告: BO-YYYYMMDD-XXX (source_contract: TR-xxx)
    ↓ 冻结后
冻结分析报告: FA-YYYYMMDD-XXX (source_contracts: [TR-xxx, BO-xxx])
```

### 1. 如果 action 为空或 "help"

展示帮助信息：

```
🔒 分析冻结工具

使用方法：
  /freeze-analysis freeze              - 冻结所有待冻结的分析报告
  /freeze-analysis freeze <target>     - 冻结指定的报告对
  /freeze-analysis freeze --force      - 强制重新冻结所有报告
  /freeze-analysis status              - 查看报告冻结状态
  /freeze-analysis list                - 查看所有冻结报告
  /freeze-analysis help                - 显示帮助

核心流程：
  1. 质量评审 - 检查三维分析质量
  2. 返工管理 - 不合格则要求返工
  3. 事实整合 - 合并三维分析
  4. 冻结锁定 - 输出不可变的事实基础

流水线位置：
  ┌─────────────────┐     ┌──────────────────┐     ┌─────────────────────┐
  │ google-trend    │ --> │ business-        │ --> │ freeze-analysis     │
  │ (热词调研)       │     │ opportunity      │     │ (分析冻结) ★当前    │
  └─────────────────┘     │ (商业机会分析)    │     └─────────────────────┘
                          └──────────────────┘              ↓
                                                    ┌─────────────────────┐
                                                    │ 后续Agent           │
                                                    │ (必须遵守冻结事实)   │
                                                    └─────────────────────┘

冻结原则：
  🔒 冻结后的事实是"权威真相"
  ⚠️ 后续Agent禁止修改或重新解释冻结事实
  ✅ 后续Agent只能基于冻结事实做决策

示例：
  /freeze-analysis freeze
  /freeze-analysis status
  /freeze-analysis freeze TR-20250103-001
```

## 错误处理

### 报告缺失

```
⚠️ 无法冻结: 缺少必需报告

热词调研报告: TR-20250103-001 ✅ 存在
商业机会报告: ❌ 缺失

请先运行以下命令生成商业机会报告:
  /analyze-opportunity

然后再运行 /freeze-analysis freeze
```

### 报告不匹配

```
⚠️ 报告关联异常

发现热词调研报告: TR-20250103-001
发现商业机会报告: BO-20250103-002

但商业机会报告的 source_contract 字段值为 TR-20250103-002，
与热词调研报告ID不匹配。

可能原因:
1. 商业机会报告是基于另一份热词调研生成的
2. 报告关联字段错误

解决方案:
1. 检查报告对应关系
2. 重新运行 /analyze-opportunity 生成正确关联的商业机会报告
```

### output目录不存在

```
如果 output 目录不存在，自动创建
```

## 质量要求

1. **评审公正**: 严格按照评审标准执行，不放水
