# 需求调研冻结

你正在使用需求调研冻结工具。本工具执行完整的需求调研冻结流程：

```
┌─────────────────────────────────────────────────────────────────────────┐
│  需求调研冻结流程                                                         │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│   Step 1: 搜索Agent输出搜索事实                                          │
│   ┌─────────────────────────────────────────────────────────────────┐   │
│   │ 读取热词调研报告 (TR-xxx) + 关键词数据                            │   │
│   └─────────────────────────────────────────────────────────────────┘   │
│                              ↓                                          │
│   Step 2: 三维并行分析                                                   │
│   ┌───────────────┬───────────────┬───────────────┐                     │

│                                                                         │

## 操作路由

### 1. 如果 action 为空或 "help"

展示帮助信息：

```
🔬 需求调研冻结工具

使用方法：
  /freeze-research freeze              - 执行完整的需求调研冻结流程
  /freeze-research freeze --from TR-xxx - 从指定热词调研开始
  /freeze-research freeze --force      - 强制重新执行
  /freeze-research status              - 查看当前冻结状态
  /freeze-research list                - 查看所有冻结报告
  /freeze-research help                - 显示帮助

核心流程：
  1. 读取搜索事实 (热词调研报告)
  2. 启动三维并行分析:
     • 用户信号分析 (user-signal-analyzer)
     • 行业结构分析 (industry-structure-analyzer)
     • 竞品供给分析 (supply-analyzer)
  3. 评审三维分析质量
  4. 整合为冻结方案
  5. 人类确认后冻结

输出：
  research-freeze.md (RF-YYYYMMDD-XXX)

下一步：
  冻结完成后运行 /freeze-opportunity 进行商业机会冻结
```

4. Glob 搜索: output/*supply*.md 或 项目根目录 *-supply-SA-*.md

- 热词调研 → 是否有对应的三维分析
- 三维分析 → 是否全部完成
- 是否已有冻结报告

### 3. 如果 action 为 "freeze"

执行完整冻结流程：

#### Step 0: 确定处理范围

**0.1 如果指定了 --from**
- 解析指定的热词调研报告
- 验证报告存在

**0.2 如果未指定 --from**
- 扫描所有热词调研报告
- 找出尚未冻结的报告
- 选择最新的进行处理

**0.3 检查是否已冻结**
- 如已冻结且未指定 --force，提示已存在
- 如指定 --force，继续处理

```
🔍 分析冻结任务

找到热词调研报告: TR-20260105-001
领域: {keyword}
调研时间: {timestamp}

检查现有分析:
  • 用户信号分析: {status}
  • 行业结构分析: {status}
  • 竞品供给分析: {status}

{下一步提示}
```

#### Step 1: 读取搜索事实

1. 读取热词调研报告
2. 提取关键数据：
   - 关键词列表
   - 波特五力原始数据
   - Top产品信息
   - 用户画像数据
   - 市场数据

```

  • 细分类别: 3
  • 波特五力: 完整

#### Step 3: 质量评审

三维分析完成后，评审质量：

**3.1 用户信号分析评审**

| 检查项 | 权重 | 合格标准 |
|--------|------|----------|
| 用户画像完整性 | 25% | 有年龄、场景、痛点 |
| 痛点数量 | 25% | ≥ 3条明确痛点 |
| 意图分析 | 25% | 有意图类型分布 |
| JTBD | 25% | 有JTBD格式表述 |

**3.2 行业结构分析评审**

| 检查项 | 权重 | 合格标准 |
|--------|------|----------|
| 行业阶段判断 | 35% | 有明确阶段（新兴/成长期/内卷）和依据 |
| 瓶颈识别 | 30% | 识别技术瓶颈或供给侧瓶颈 |
| 结构性空位 | 35% | 有是否存在空位的判断和理由 |

**3.3 竞品供给分析评审**

| 检查项 | 权重 | 合格标准 |
|--------|------|----------|
| 竞品数量 | 25% | ≥ 3个主要竞品 |
| Gaps识别 | 30% | ≥ 2类Gap |
| 产品信息 | 25% | 有定价、功能、缺点 |
| 来源标注 | 20% | ≥ 70%有来源 |

#### Step 4: 整合冻结方案

评审通过后，整合三维分析生成冻结方案：

**4.1 提取核心事实**

从三份报告中提取：

```yaml
user_signal_facts:
  primary_persona: {...}
  pain_points: [...]
  intent_distribution: {...}
  jtbd: [...]

industry_structure_facts:
  porter_five_forces: {...}
  market_stage: {...}
  market_concentration: {...}
  entry_barriers: {...}

supply_facts:
  top_competitors: [...]
  supply_gaps: [...]
  differentiation_opportunities: [...]
```

**4.2 识别核心假设**

从三份报告的"待确认事项"中整合：

```yaml
accepted_assumptions:
  - {assumption_1}
  - {assumption_2}

assumptions_to_verify:
  - {assumption_3}
  - {assumption_4}
```

**4.3 生成冻结方案**

生成供人类确认的冻结方案，包含4个确认点：

1. **确认点1**: 用户信号分析结论
2. **确认点2**: 行业结构分析结论
3. **确认点3**: 竞品供给分析结论
4. **确认点4**: 核心假设汇总

## 错误处理

### 热词调研报告缺失

```
❌ 无法执行需求调研冻结

原因: 未找到热词调研报告

请先运行以下命令:
  /google-keywords {关键词}  # 关键词搜索
  /google-trend              # 热词调研

然后再运行 /freeze-research freeze
```

### 分析报告生成失败

```
⚠️ 分析生成失败

失败的分析: 行业结构分析

可能原因:
1. 热词调研报告数据不完整
2. 网络搜索无法获取数据

建议:
1. 检查热词调研报告是否完整
2. 手动运行 /analyze-industry 单独生成
3. 重新运行 /freeze-research freeze
```

## 输出要求

1. **进度透明**: 每个步骤都要显示进度
2. **评审严格**: 按照评审标准打分，不放水
3. **确认完整**: 4个确认点都必须获得人类确认
4. **事实纯粹**: 冻结内容只包含事实，不含判断
5. **追溯完整**: 所有事实可追溯到源报告
