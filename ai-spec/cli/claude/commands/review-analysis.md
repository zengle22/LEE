# 审批分析报告

你正在执行分析报告的审批任务。

## 任务说明

帮助审批者完成产品目标价值分析报告的审批流程。

## 执行步骤

### 1. 查找待审批报告

$report

如果未指定报告，扫描 `output/` 目录，列出所有待审批的分析报告。

展示格式：
```
📋 待审批报告列表

1. {需求标题}
   - 文件：{文件名}
   - 分析时间：{时间}
   - 综合评分：{评分}
   - 优先级：{P0/P1/P2/P3}

2. ...
```

### 2. 展示报告摘要

当用户选择某个报告后，读取并展示关键信息：

```
📊 报告摘要

## 需求信息
- 标题：{标题}
- 提交人：{提交人}

## 核心目标
- {主要目标}

## 业务价值链
用户需求 → 产品功能 → 直接价值 → 业务影响 → 战略意义

## 维度评分
| 维度 | 评分 |
|------|------|
| 用户价值 | {评分} |
| 行业情况 | {评分} |
| 生产效率 | {评分} |
| 成本管理 | {评分} |

## 主要风险
- {风险1}
- {风险2}

## 综合评估
- 综合评分：{评分}
- 优先级建议：{优先级}
```

### 3. 收集审批信息

向用户询问：

1. **审批人姓名**
2. **审批决定**：
   - ✅ 通过 - 可进入下一环节
   - 🔄 需修订 - 请提供修订建议
   - ❌ 拒绝 - 请说明拒绝原因
3. **审批意见**

### 4. 记录审批结果

在 `output/` 目录生成审批结果文件：

文件名：`{日期}_审批结果_{需求标题}.md`

内容：
```markdown
# 审批结果

## 基本信息
| 项目 | 内容 |
|------|------|
| 需求标题 | {标题} |
| 审批人 | {审批人} |
| 审批时间 | {时间} |
| 审批结果 | {结果} |

## 审批意见

{审批意见内容}

{如果需修订，列出修订建议}

## 下一步

{根据审批结果给出指导}
```

### 5. 通知结果

根据审批结果向用户反馈：

**通过**：
```
🎉 审批通过！

需求「{标题}」已获批准，可进入下一工作环节。

审批记录：{审批文件路径}
```

**需修订**：
```
📝 需要修订

请根据以下建议修改后重新提交分析：
- {建议1}
- {建议2}

修改完成后，请使用 /analyze-requirement 重新分析。
```

**拒绝**：
```
❌ 审批未通过

原因：{拒绝原因}

如有疑问，请与审批人沟通。
```

## 重要原则

1. **不能自动审批** - 必须等待用户明确表达审批决定
2. **完整记录** - 审批信息必须完整保存
3. **流程透明** - 展示审批的每个步骤
4. **状态清晰** - 明确告知当前状态和下一步
