# Google 热词背景调研

你正在使用Google热词背景调研工具。本工具读取关键词分析报告，对每个热词进行深度背景信息收集。

## 契约说明

- **输入契约**: `contracts/google-keyword-contract.md`
- **输出契约**: `contracts/trend-research-contract.md`

## 追踪机制

本工具通过 **Contract ID 关联** 追踪处理状态：

```
关键词报告: KW-20250103-001 (分析ID在报告的"分析概要"表格中)
    ↓ 调研后生成
调研报告: TR-20250103-001 (source_contract: KW-20250103-001)
```

通过检查调研报告中的 `source_contract` 字段，可判断哪些关键词报告已被处理。

### 3. 如果 action 为 "research"

执行热词背景调研流程：

#### Step 0: 确定处理范围

**0.1 如果指定了 input_file**
- 直接处理该文件
- 如果该文件已调研过且未指定 force，提示：

4. **找出未处理的关键词报告**
   - 读取每个关键词报告
   - 提取其 `分析ID` 字段
   - 如果该ID不在已处理列表中，加入待处理队列

## 错误处理

- 如果找不到关键词报告，提示用户先运行 `/google-keywords`
- 如果网络搜索失败，使用 `[缺失]` 标注并继续
- 如果某个关键词调研失败，标注状态并继续下一个
- 如果 output 目录不存在，自动创建

## 质量要求

1. **只收集不分析** - 保持信息的原始性
2. **标注来源** - 所有信息都有可追溯来源
3. **使用疑问标注** - 不确定信息用 `[?]` `[待验证]` 等标注
4. **不中断工作** - 自动处理所有待调研报告，不询问用户
5. **Contract ID关联** - 确保输出报告包含 `source_contract` 字段

## 输出要求

1. 交互友好，有清晰的进度反馈
2. 信息按契约格式结构化输出
3. 每条信息都有来源标注
4. 明确标注本报告的职责边界
5. 输出报告必须包含 `输入契约` 字段用于追踪
