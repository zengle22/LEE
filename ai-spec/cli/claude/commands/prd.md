# 产品目标价值分析

你正在使用产品目标价值分析工具。

## 操作指引

根据用户的操作类型执行相应功能：

### 参数解析

**action**: $action
**content**: $content

---

## 操作路由

### 1. 如果 action 为空或 "help"

展示帮助信息：

```
🎯 产品目标价值分析工具

使用方法：
  /prd analyze <需求描述>  - 分析产品需求
  /prd review              - 审批分析报告
  /prd list                - 查看所有报告
  /prd help                - 显示帮助

功能说明：
  • 从用户价值、行业情况、生产效率、成本管理四个维度分析需求
  • 提取核心目标，构建业务价值穿达链
  • 生成标准化Markdown报告
  • 支持人工审批工作流

示例：
  /prd analyze 我们需要开发一个智能客服机器人...
  /prd review
```

### 2. 如果 action 为 "analyze"

执行需求分析流程：

1. **获取需求内容**
   - 如果 content 有值，使用该内容作为需求描述
   - 如果 content 为空，询问用户提供需求信息

2. **收集完整信息**（如果content不够详细）
   - 需求标题
   - 详细描述
   - 目标用户
   - 期望上线时间（可选）
   - 提交人
   - 补充上下文（可选）

3. **调用分析skill**
   使用 `product-goal-analysis` skill 进行多维度分析

4. **生成报告**
   - 使用标准模板生成Markdown报告
   - 保存到 `output/` 目录
   - 文件名格式：`{YYYY-MM-DD}_{需求标题}_分析报告.md`

5. **展示结果摘要**
   ```
   ✅ 分析完成！

   📊 分析摘要：
   | 维度 | 评分 |
   |------|------|
   | 用户价值 | {评分} |
   | 行业情况 | {评分} |
   | 生产效率 | {评分} |
   | 成本管理 | {评分} |

   综合评分：{评分}
   优先级建议：{P0/P1/P2/P3}

   📄 报告路径：output/{文件名}

   ⚠️ 请使用 /prd review 进行人工审批
   ```

### 3. 如果 action 为 "review"

执行审批流程：

1. **扫描待审批报告**
   - 读取 `output/` 目录下的 `*_分析报告.md` 文件
   - 检查审批状态（查找"⏳ 待审批"标记）

2. **如果 content 指定了报告**
   - 直接打开该报告进行审批

3. **如果 content 为空**
   - 列出所有待审批报告
   - 询问用户选择

4. **展示报告摘要**
   - 需求标题和描述
   - 核心目标
   - 各维度评分
   - 综合评估

5. **收集审批决定**
   - 审批人姓名
   - 审批结果：✅通过 / 🔄需修订 / ❌拒绝
   - 审批意见
   - 修订建议（如果需修订）

6. **保存审批结果**
   - 生成审批结果文件
   - 文件名：`{日期}_审批结果_{需求标题}.md`

### 4. 如果 action 为 "list"

列出所有分析报告：

1. 扫描 `output/` 目录
2. 展示报告列表：
   ```
   📋 分析报告列表

   状态 | 需求标题 | 分析时间 | 优先级
   -----|----------|----------|--------
   ⏳   | {标题1}  | {时间}   | P1
   ✅   | {标题2}  | {时间}   | P0
   ❌   | {标题3}  | {时间}   | P2

   共 {n} 份报告，其中 {m} 份待审批
   ```

---

## 错误处理

- 如果 action 不是有效值，提示正确的使用方法
- 如果 output 目录不存在，自动创建
- 如果没有待审批报告，友好提示

## 输出要求

1. 保持交互友好
2. 关键信息高亮显示
3. 每步操作有清晰反馈
4. 审批必须由人类明确决定
