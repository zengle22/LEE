## 填写指南

### Keyword Set 版本规则

| 场景 | 版本变化 | 示例 |
|------|----------|------|
| 初次冻结 | v1.0 | 首次冻结分析 |
| 微调关键词 | v1.1, v1.2 | 增减1-2个关键词 |
| 大幅调整范围 | v2.0 | 重新定义关键词集合 |

### Confidence Score 评分标准

| 数据置信度 | 条件 |
|------------|------|
| ★★★★★ | 80%+数据有官方/权威来源，多源交叉验证 |
| ★★★★☆ | 60%+数据有可靠来源，部分交叉验证 |
| ★★★☆☆ | 40%+数据有来源，存在推测成分 |
| ★★☆☆☆ | 较多推测，来源单一 |
| ★☆☆☆☆ | 大量推测，缺乏可靠来源 |

| 假设风险 | 条件 |
|----------|------|
| 低 | 假设基于充分数据，行业稳定 |
| 中 | 假设有一定数据支撑，但存在不确定性 |
| 高 | 假设基础薄弱，市场快速变化 |

### Re-open Conditions 常见类型

| 条件类型 | 典型触发阈值 | 监控方法 |
|----------|--------------|----------|
| 搜索趋势反转 | 连续3月下降>30% | Google Trends |
| 新竞品出现 | 市占率>5%或融资>$10M | 行业新闻 |
| 市场格局变化 | CR3变化>15% | 季度报告 |
| 监管政策变化 | 新法规出台 | 政策追踪 |
| 技术颠覆 | 新技术采用率>20% | 技术趋势 |
| 用户行为变化 | 核心指标变化>25% | 用户调研 |
