# 需求对齐 Agent

> 在进入开发环节前，确保需求清晰、完整、无歧义

## 简介

需求对齐 Agent 是一个帮助你在开发前澄清需求的工具。它会：

1. **分析** 你的需求，识别潜在问题
2. **提问** 关键决策点，提供选项和推荐
3. **确认** 你的决策，生成明确的需求规格
4. **把关** 确保需求明确后才能进入下一环节

## 使用方法

### Claude Code

将以下内容添加到你的 `.claude/commands/` 目录：

```bash
# 创建命令目录
mkdir -p .claude/commands

# 复制 agent 文件
cp agents/requirement-alignment/agent.md .claude/commands/align-requirement.md
```

然后使用 `/align-requirement` 命令启动。

### Cursor

在 Cursor 的 Rules 中引入：

```
@agents/requirement-alignment/agent.md
```

或在对话中直接引用文件。

### 通用方式

直接将 `agent.md` 的内容作为 system prompt，或在对话开始时引用。

## 示例对话

**用户**: 我需要做一个评论功能

**Agent**:
```
🔍 需求分析报告

原始需求: 我需要做一个评论功能

发现的问题:

问题 1: 评论层级不明确
- 类型: 缺失
- 影响: 决定数据结构和 UI 复杂度

选项:
| 选项 | 描述 | 优点 | 缺点 |
|------|------|------|------|
| A | 单层评论 | 简单易实现 | 无法回复讨论 |
| B (推荐) | 两层评论 (评论+回复) | 满足多数场景 | 复杂度适中 |
| C | 无限层级 | 最灵活 | 实现复杂，展示困难 |

你的选择: [ ]

问题 2: 是否需要审核机制？
...
```

**用户**: 问题1选B，问题2选A

**Agent**:
```
✅ 决策确认

| # | 问题 | 决策 |
|---|------|------|
| 1 | 评论层级 | B - 两层评论 |
| 2 | 审核机制 | A - 无需审核 |

确认以上决策正确吗？确认后将生成完整需求规格。
```

## 自定义

### 添加分析维度

编辑 `agent.md` 中的"分析维度"部分，添加适合你业务的检查项。

### 调整输出格式

编辑 `output-templates.md`，根据团队习惯调整文档格式。

### 扩展分析模式

编辑 `analysis-patterns.md`，添加你领域常见的问题模式。

## 最佳实践

1. **尽早使用**: 在任何开发工作开始前进行需求对齐
2. **保留记录**: 将最终规格文档存档，便于后续追溯
3. **迭代完善**: 根据实际使用不断完善分析模式
4. **团队协作**: 鼓励团队成员一起参与需求对齐
