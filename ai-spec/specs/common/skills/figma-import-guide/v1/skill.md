# Figma 导入指南

本指南帮助你将原型设计 Agent 生成的文件导入 Figma 进行进一步编辑。

## 支持的导入格式

### SVG 格式（推荐）
- **优点**: 完全矢量化，可编辑所有元素
- **适用**: 线框图、图标、简单界面
- **Figma 中**: 每个元素都可独立选中和编辑

### PDF 格式
- **优点**: 保持高保真视觉效果
- **适用**: 复杂设计稿、多页文档
- **Figma 中**: 需要使用插件转换为可编辑元素

### PNG 格式
- **优点**: 通用性强，任何工具都能打开
- **适用**: 快速预览、演示
- **Figma 中**: 作为参考图层，需手动重绘

## 导入步骤

### 方法一：直接拖放（SVG/PNG/PDF）

1. 打开 Figma 并创建或打开一个项目
2. 找到生成的设计文件
3. 将文件直接拖放到 Figma 画布上
4. 调整位置和大小

### 方法二：使用菜单导入

1. 在 Figma 中选择 **File → Place Image** (或按 `Ctrl/Cmd + Shift + K`)
2. 选择要导入的文件
3. 点击画布放置

### 方法三：复制粘贴 SVG 代码

1. 在代码编辑器中打开 SVG 文件
2. 复制全部 SVG 代码
3. 在 Figma 中按 `Ctrl/Cmd + V` 粘贴
4. SVG 元素会自动转换为 Figma 图层

## 导入后的处理

### SVG 文件导入后

1. **解组**: 右键 → Ungroup (或 `Ctrl/Cmd + Shift + G`)
2. **重命名图层**: 双击图层名进行重命名
3. **创建组件**: 选中重复元素 → 右键 → Create Component
4. **应用自动布局**: 选中容器 → 按 `Shift + A`

### PDF/PNG 文件导入后

**使用 html.to.design 插件（推荐）:**
1. 安装 Figma 插件 "html.to.design"
2. 打开生成的 HTML 原型 URL
3. 使用插件一键转换为 Figma 设计

**手动转换:**
1. 将 PDF/PNG 作为参考图层
2. 锁定参考图层 (右键 → Lock/Unlock)
3. 在上方新建图层，手动重绘元素
4. 使用 Figma 的吸色工具提取颜色

## 推荐的 Figma 插件

### 导入转换类
- **html.to.design**: 将 HTML 网页转换为 Figma 设计
- **Image Tracer**: 将位图转换为矢量图形
- **PDF Import**: 增强的 PDF 导入功能

### 设计增强类
- **Figma Tokens**: 管理设计令牌
- **Content Reel**: 快速填充真实内容
- **Iconify**: 海量图标库

## 最佳实践

### 1. 建立设计系统
导入后，将重复使用的元素创建为 Figma 组件：
- 按钮（主要、次要、禁用状态）
- 输入框（默认、聚焦、错误状态）
- 卡片（不同尺寸和变体）
- 导航栏

### 2. 使用自动布局
为容器添加自动布局，使设计更灵活：
- 选中容器
- 按 `Shift + A` 添加自动布局
- 调整间距和对齐方式

### 3. 创建样式
将颜色和文字样式保存为 Figma 样式：
- 颜色: 选中元素 → 填充面板 → 四点图标 → Create Style
- 文字: 选中文字 → 文字面板 → 四点图标 → Create Style

### 4. 组织图层
保持图层结构清晰：
```
页面名称/
├── Header/
│   ├── Logo
│   ├── Navigation
│   └── User Menu
├── Main Content/
│   ├── Hero Section
│   └── Feature Cards
└── Footer/
    ├── Links
    └── Copyright
```

## 常见问题

### Q: SVG 导入后文字变成了路径怎么办？
A: 这是因为 SVG 中的文字被转换为了轮廓。解决方案：
1. 删除路径化的文字
2. 使用 Figma 的文字工具重新添加
3. 或在生成 SVG 时保留文字为 `<text>` 元素

### Q: 导入的颜色和原设计不一致？
A: 检查颜色空间设置。Figma 默认使用 sRGB，确保导出时也使用相同的颜色空间。

### Q: 如何批量导入多个文件？
A:
1. 选择所有文件
2. 一起拖入 Figma
3. 每个文件会成为独立的 Frame
