# Product Specification System (v1.0)
# 产品部门规范体系

本目录包含了产品部门在需求分析阶段的核心规范、Agent 定义及工作流。遵循 **以价值为导向，以问题为核心** 的原则，通过标准化的契约（Contract）实现 Agent 间的高效协作与人类关键决策的冻结。

## 🌟 核心理念

1. **价值驱动**：所有需求必须可追溯到冻结的业务价值。
2. **问题空间优先**：在思考解决方案（功能）之前，必须先定义清楚问题空间。
3. **人类冻结**：Agent 负责分析与生成，人类负责在关键决策点进行“冻结”操作。

## 🔄 产品决策流水线 (Product Pipeline)

该流水线串联了从商业机会到需求冻结的完整过程，包含两次关键的人类冻结确认。

### 阶段 1：价值定义 (Value Definition)
*   **Agent**: `agent.analysis.product_goal@common`
*   **输入**: 商业机会冻结 (Business Opportunity Freeze)
*   **输出**: 产品价值提案 (Product Value Proposal)
*   **🔒 冻结点 1**: **产品价值冻结 (Product Value Freeze)** - 确认“做什么产品”以及“核心指标”。

### 阶段 2：问题空间翻译 (Problem Translation)
*   **Agent**: `agent.product.requirement_alignment@v1`
*   **输入**: 产品价值冻结
*   **输出**: 问题定义 (Problem Definition) - 明确 Before/After 旅程与 Non-goals。

### 阶段 3：需求拆解 (Requirement Decomposition)
*   **Agent**: `agent.product.requirement_decomposer@v1`
*   **输入**: 问题定义
*   **输出**: 需求拆解 (Requirement Breakdown) - 结构化需求单元清单。

### 阶段 4：需求评审与对齐 (Requirement Review)
*   **Agent**: `agent.review.requirement_reviewer@common`
*   **输入**: 产品价值冻结 + 需求拆解
*   **输出**: 需求评审报告 (Requirement Review Report)
*   **🔒 冻结点 2**: **需求冻结 (Requirement Freeze)** - 确认需求与价值对齐，准备交付研发。

## 🚀 后续衔接
