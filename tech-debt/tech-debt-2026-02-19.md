## 严重问题 (P0) - 需要立即修复

### P0-001: Gate API 使用内存存储，数据丢失风险

**位置**: `src/lee/orchestrator/execution/gate_api.py:70`
**类别**: 安全/数据持久化
**估计工时**: 2-3 天

**问题描述**:
GateAPI 类使用临时字典 `_gates` 存储门禁状态，代码注释明确指出应该存储在数据库但未实现。这会导致进程重启后所有待审批的门禁丢失，造成工作流无法恢复。

**影响**:
- ⚠️ 数据丢失风险极高
- ⚠️ 工作流中断后无法恢复
- ⚠️ 违反数据持久化原则
- ⚠️ 生产环境不可用

**建议修复**:
```python
# 当前实现 (第 69-70 行)
# 临时存储 gate 请求（实际应该存储在数据库）
self._gates: Dict[str, GateRequest] = {}

# 建议实现
# 使用 SQLiteStore 持久化门禁状态
```

**优先级**: 🔴 立即修复
