#### TD-001: SQL Injection Risk
- **Location:** `src/lee/orchestrator/storage/sqlite_store.py:344,348,470,474`
- **Issue:** Using f-string concatenation for SQL SET clauses
- **Impact:** Potential SQL injection if column names are user-controlled

- **Effort:** 2-4 hours

#### TD-003: Command Injection via shell=True

- **Issue:** subprocess.Popen uses shell=True by default
- **Impact:** Arbitrary command execution

#### TD-005: Path Traversal Vulnerability

- **Effort:** 2-3 hours

      - id: shellcheck
